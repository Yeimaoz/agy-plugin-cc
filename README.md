# agy-plugin-cc

Use Google Antigravity CLI (`agy`) from Claude Code: multi-model code review, rescue and task delegation. Command-for-command parity with `openai/codex-plugin-cc`, plus real model choice (Gemini 4 Argon, Gemini 3.8 Flash, Claude Opus / Sonnet 5.5, GPT-OSS 120B).

## Install

```
/plugin marketplace add Yeimaoz/agy-plugin-cc
/plugin install agy@agy-plugin-cc
/agy:setup
```

Requires Node >= 18.18 and the Antigravity CLI (`agy`) logged in.
